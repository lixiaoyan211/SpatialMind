# SpatialMind 实验结果

## 研究问题与协议

任务是判断自然图片中的英文空间关系描述是否为真，输出严格的 `True` 或 `False`。比较未经微调的 Qwen3.5-2B 与同一基础模型的 LoRA Adapter。Random 和 Zero-shot 分别使用各自的训练、验证、测试划分训练独立 Adapter；验证集选 checkpoint，测试集只用于最终评测。

数据来自 [VSR 官方项目](https://github.com/cambridgeltl/visual-spatial-reasoning)及其 [Zero-shot 数据页](https://huggingface.co/datasets/cambridgeltl/vsr_zeroshot)。Random 为 7,680／1,097／2,195 条；当前 Zero-shot JSONL 实际为 3,489／340／1,222 条。作者仓库 README 仍列出另一组 Zero-shot 数量，本项目按下载并校验的实际文件运行。Zero-shot 的官方 `dev` 在转换后命名为 `validation`，评测脚本也能直接读取原始 `dev`。图片从 COCO 准备；本机两个划分共用已校验的图片目录。

## 固定设置

- 基础模型：Qwen3.5-2B 本地权重；权重文件 SHA-256 见项目 README。运行环境为 Python 3.11、PyTorch 2.6.0+cu126、Transformers 5.2.0、ms-swift 4.7.0.dev0。
- 提示词与答案解析：统一使用 `src/inference.py`；相同测试集内的 Base／LoRA 配置仅 Adapter 路径不同。
- 推理：图像 token 上限 512，最多生成 8 token，temperature 0；两组均无无法解析的输出。
- 训练：LoRA rank 8、alpha 32、学习率 1e-4、每卡 batch size 1、梯度累积 4、bfloat16、冻结视觉模块与对齐器、随机种子 42、1 epoch。每 100 个优化步骤验证并保存，按最低验证 loss 选 checkpoint。
- 硬件：本地 RTX 4060 Laptop GPU，8GB 显存。两组训练和完整评测均在本地完成，未租云 GPU。

复现命令与本机路径参数见项目 README。`output/` 含逐条预测、配置、训练日志和 Adapter，因体积及本机路径未纳入 Git；本报告汇总可发布的结果。要逐条复核结果，应在本地保留这些原始产物或另行发布归档。

## 完整测试集结果

| 划分 | 模型 | 样本 | Accuracy | Precision | Recall | F1 | 无效输出 |
|---|---|---:|---:|---:|---:|---:|---:|
| Random | Base | 2,195 | 73.17% | 86.91% | 59.02% | 70.30% | 0 |
| Random | LoRA（checkpoint-1700） | 2,195 | 85.60% | 88.17% | 84.59% | 86.34% | 0 |
| Zero-shot | Base | 1,222 | 77.00% | 84.52% | 67.73% | 75.20% | 0 |
| Zero-shot | LoRA（checkpoint-800） | 1,222 | 83.80% | 80.06% | 91.26% | 85.29% | 0 |

同一划分内，Random 的 LoRA − Base Accuracy 为 **+12.44 个百分点**，F1 为 **+16.05 个百分点**；Zero-shot 分别为 **+6.79** 和 **+10.09 个百分点**。Random 中 LoRA 新答对 370 条、改错 97 条；Zero-shot 中新答对 172 条、改错 89 条。两组测试集不同，不能把它们的准确率差值当作纯粹的“未见物体”效应。

| 划分 | 模型 | TP | TN | FP | FN |
|---|---|---:|---:|---:|---:|
| Random | Base | 697 | 909 | 105 | 484 |
| Random | LoRA | 999 | 880 | 134 | 182 |
| Zero-shot | Base | 426 | 515 | 78 | 203 |
| Zero-shot | LoRA | 574 | 450 | 143 | 55 |

Zero-shot 中 LoRA 的 Precision 下降 4.47 个百分点，同时 Recall 上升 23.53 个百分点。真实 False 样本中，它新增 87 条假阳性并纠正 22 条，假阳性净增 65 条；真实 True 样本中，它纠正 150 条假阴性并新增 2 条。这些是完整测试集的逐条配对计数。

## 案例观察与训练记录

Random 和 Zero-shot 各抽取 30 条案例，分别包含 LoRA 相对官方标签改对、改错、两者都错各 10 条。项目作者已分别完成 [Random 报告](error_analysis.md)和 [Zero-shot 报告](zeroshot_error_analysis.md)的人工复核；人工判断与官方标签分别有 11 条和 7 条分歧。案例分组与完整测试集指标仍按官方标签计算。人工分歧不等于已证实的标签错误；两组都是定向抽样，不能估计全测试集错误类型比例。记录中涉及“在物体内／在物体上”、主客体顺序、相邻、距离和朝向等问题。

Random 训练 1,920 步，最低验证 loss 0.10905512，对应 checkpoint-1700。训练日志墙钟跨度约 19 小时 18 分钟，其中第 1385 至 1390 步约 11 小时 54 分钟无进展；扣除间隔，活跃时间约 7 小时 24 分钟。

Zero-shot 训练 873 步，最低验证 loss 0.12326923，对应 checkpoint-800；训练日志峰值显存 4.62 GiB。墙钟跨度约 13 小时 21 分钟，其中第 595 至 600 步约 10 小时 26 分钟无进展；扣除间隔，活跃时间约 2 小时 55 分钟。日志无法单独确定这些间隔的原因。两组结果都来自单个随机种子，尚未重复训练或计算置信区间。

## 结论边界

两种划分内 LoRA 都提高了 Accuracy 和 F1，说明该配置在对应测试集上有实测收益。Zero-shot 协议用于观察未见物体概念上的判断，但与 Random 的训练规模、测试样本和关系分布也不同；跨划分比较不能证明概念未见是唯一原因。两组案例中的人工分歧均为单人定性判断。若要将其作为数据标签问题的正式结论，应由第二位标注者独立复核，并记录判断依据与分歧。
